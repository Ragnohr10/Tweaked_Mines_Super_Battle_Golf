# Tweaked Mines

`Tweaked mines for **Super Battle Golf**`.

## Features
`- Reduced Landmine quantity from 3 to 1`
`- Reduced landmine detection`

## Installation
- Place this package into the game folder so the DLL ends up at `BepInEx/plugins/SBGMultiGoals/Tweaked_Mines.dll`.

## Version
- `1.0.0`
